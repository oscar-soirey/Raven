# Raven for Odin, the idiomatic layer

`raven_odin` is a hand-written layer over the generated binding in `../raven`
(which stays as it is and is used here as the raw package). It is optional:
programs that import `raven` keep working.

What it changes for the user:

- Odin `string` and `bool` instead of `cstring` and `i32`.
- Values written through pointers come back as results:
  `width, height := raven.window_get_size(window)`.
- Handles are separate types (`Window`, `Widget`, `Timer`): passing a window
  where a widget is expected does not compile.
- Enums are Odin enums (`.Left`, `.Label`) and flag groups are `bit_set`s.
- Callbacks are normal Odin procedures. No `proc "c"`, and the `context` of
  the code that registered the callback is restored when it runs.

```odin
package hello

import raven "ext:raven_odin"

main :: proc() {
	if !raven.init() {
		return
	}
	raven.window_create_from_xml(`<Window Title="Hi"><Button Text="Quit" OnClicked="quit"/></Window>`)
	raven.action_bind("quit", proc(sender: raven.Widget, action: string, data: rawptr) {
		raven.quit()
	})
	for raven.wait_frame() {}
	raven.shutdown()
}
```

Point a collection at the bindings folder and link the shared library as for
the raw binding (see `../README.md`):

    odin run . -collection:ext=<Raven>/bindings/odin -extra-linker-flags:"-L/path/to/lib -Wl,-rpath,/path/to/lib"

The package is named `raven_odin` because Odin refuses two packages of the
same name in one build; the import alias gives `raven.` in the code.

## What is here

| File | Content |
|---|---|
| `enums.odin` | Generated by `tools/bindgen` (`gen_odin_wrapper.py`): all C enums, with `bit_set`s for the flag groups. Checked by `bindgen.py --check`. |
| `handles.odin`, `core.odin` | Typed handles; `init`, `shutdown`, `quit`, `draw_frame`, `wait_frame`. |
| `callbacks.odin` | Actions and timers with Odin procedures. |
| `window.odin`, `widget.odin` | Windows from XML, size and title, input injection, XML parsing with the position of a mistake, widget lookup, labels and text inputs. |
| `example/main.odin` | The example of `../example` through this layer. `-- --test` runs it without a window. |
| `callbacks_test.odin` | `odin test`, headless, with a tracking allocator. |

This is a first part. The rest of the C API is available through the raw
package (`import raw "ext:raven"`) in the same program.
