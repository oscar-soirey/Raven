# Raven for Swift

A Swift package: `import Raven` gives the whole C API of Raven, read by Swift
from the headers of `include/` (the same names and the same documentation as
in C), and a few helpers for closures and texts.

Generated by `tools/bindgen` (`gen_swift.py`): do not edit these files, edit
the generator.

## Use

Build the shared library of Raven (`cmake -B build -DRAVEN_BUILD_SHARED=ON`,
`cmake --build build`), then add the package to yours by its path:

```swift
// Package.swift
dependencies: [
    .package(path: "<raven>/bindings/swift"),
],
targets: [
    .executableTarget(name: "App", dependencies: [.product(name: "Raven", package: "swift")]),
]
```

and tell the linker where the library is:

    RAVEN_LIB_DIR=/path/to/lib swift run

(`RAVEN_LIB_DIR` also gives the program an rpath to the library; without it,
`swift build -Xlinker -L/path/to/lib` and put the library where the program
finds it.)

The example of this folder:

    RAVEN_LIB_DIR=/path/to/lib swift run hello           # a window
    RAVEN_LIB_DIR=/path/to/lib swift run hello --test    # no window system, no GPU: what ctest runs

## From Swift

```swift
import Raven

Rinit(R_BACKEND_VULKAN)
let window = windowFromXml("""
    <Window Title="Hello" Width="320" Height="160">
        <VBox Spacing="10" Slot.Padding="16">
            <TextInput Name="name" Placeholder="Your name"/>
            <Button Text="Greet" Style="Primary" OnClicked="greet"/>
        </VBox>
    </Window>
    """)
let name = Rwidget_find(window, "name")
actionBind("greet") { _, _ in print("Hello,", text(Rtext_input_get_text(name))) }
while Rwait_frame(-1) != 0 {}
Rshutdown()
```

- **Texts.** A Swift `String` goes wherever C takes a `const char*`
  (`Rlabel_set_text(label, "Hi")`). A text of the library comes back as a
  pointer: `text(pointer)` makes it a `String`, and `text(fixed:)` reads a
  `char` array of a structure (a tuple in Swift).
- **Pointers to values** are `inout`: `Rwidget_get_rect(id, &x, &y, &w, &h)`.
- **Structures** start zeroed with `RInitDesc()`.
- **Enumerations** keep their C names (`R_BACKEND_NULL`, `R_WIDGET_LABEL`)
  and compare with `==`.
- **Callbacks.** A C callback takes a closure that captures nothing. To give a
  closure that does, use `actionBind`, `timerStart` (stopped by `timerStop`)
  or `errorSetCallback`; the closures are kept until they are replaced.
  For other callbacks, bind an action (`OnClicked="name"` in XML,
  `Rwidget_set_action`), or pass a context through their `user_data`
  (`Unmanaged.passRetained(object).toOpaque()`).
- **Threads.** Raven belongs to the thread that starts it: call it from that
  thread only.

`raven_backend.h` and `raven_vulkan.h` are left out, as in the other bindings.

Tested on macOS and Linux (Swift 5.9 or later). Windows is not tested.
